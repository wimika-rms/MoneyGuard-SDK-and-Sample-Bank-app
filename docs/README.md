# Behavioral Biometrics Documentation

This folder contains professional SVG diagrams for the Behavioral Biometrics Authentication feature.

## Files

### 📊 Flowcharts

1. **[flowchart-main-login.svg](./flowchart-main-login.svg)**
   - Complete user journey from app open to dashboard
   - Shows enrollment and verification flows
   - Includes decision points and all user scenarios
   - **Use for:** Executive presentations, technical reviews

2. **[flowchart-cross-device.svg](./flowchart-cross-device.svg)**
   - Cross-device login scenario
   - Trusted device verification process
   - Success and failure paths
   - **Use for:** Security presentations, UX discussions

### 🏗️ Architecture

3. **[architecture-diagram.svg](./architecture-diagram.svg)**
   - System components and their interactions
   - Data flow between mobile app and backend services
   - Technology stack overview
   - **Use for:** Technical architecture reviews, developer onboarding

## How to View

### In Browser
Simply open any `.svg` file in a web browser:
- Double-click the file (will open in default browser)
- Or drag & drop into browser window

### In Presentations
**PowerPoint/Keynote:**
1. Insert → Pictures → Select SVG file
2. SVG will be crisp at any size (vector graphics)

**Google Slides:**
1. Insert → Image → Upload from computer
2. Select SVG file

### In Documentation Tools
**Markdown:**
```markdown
![Diagram Name](./path/to/diagram.svg)
```

**Confluence/Notion:**
- Upload as attachment
- Embed in page

## Editing SVGs

These SVGs can be edited in:
- **Adobe Illustrator** - Full professional editing
- **Inkscape** (Free) - Open-source vector editor
- **Figma** (Free) - Browser-based design tool
- **Text Editor** - SVGs are XML, can edit directly
